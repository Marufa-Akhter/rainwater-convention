🏞️ Rainwater Convention – 4 Page Website

A simple static website built using HTML, CSS, and JavaScript, created for the Rainwater Convention assignment.

📌 Project Description

This is a 4-page website created to promote the Rainwater Convention event and allow users to register for participation. The website contains:

Home Page

FAQs Page

Registration Page (with form validation & localStorage saving)

Admin Page (shows registered users)

This project does not use any backend. All data is handled with localStorage inside the browser.
