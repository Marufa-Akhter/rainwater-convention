# 🏞️ Rainwater Convention – 4 Page Website

A simple 4-page static website built using HTML, CSS, and JavaScript for the Rainwater Convention assignment.

---

## 📌 Project Description

This is a 4-page website created to promote the Rainwater Convention event and allow users to register for participation.

The website contains:

- **Home Page**
- **FAQs Page**
- **Registration Page** (with form validation & localStorage saving)
- **Admin Page** (shows registered users)

The project does not use any backend. All data is handled using **localStorage** in the browser.

## 🚀 Features

### 🏠 Home Page
- Introduction to the Rainwater Convention  
- Background image included

### ❓ FAQs Page
- Common questions with answers

### 📝 Registration Page
- User form with required field validation  
- Email format validation  
- Data saved in **localStorage**

### 🔐 Admin Page
- Reads user data from **localStorage**  
- Shows all registered participants in a table  
- Simple admin panel (no login required)
